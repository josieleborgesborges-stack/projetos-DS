# 🛒 Sistema de Desconto Progressivo em Python

> Projeto desenvolvido como parte de uma atividade prática para implementação de lógica de programação e regras de negócio em Python.

## 📋 Sobre o Projeto

Este programa calcula de forma automatizada o desconto progressivo aplicável a uma compra em uma loja online, com base em faixas de valores pré-estabelecidas. O sistema solicita o valor total da compra ao usuário, determina o percentual de desconto correspondente, calcula os valores monetários e exibe um resumo detalhado da transação.

---

## 🎯 Regras de Desconto

| Faixa de Valor da Compra | Percentual de Desconto |
| :--- | :---: |
| Menor que **R$ 200,00** | **5%** |
| De **R$ 200,00** até **R$ 299,99** | **10%** |
| Maior ou igual a **R$ 300,00** | **15%** |

---

## ⚙️ Funcionalidades

* **Cálculo Progressivo:** Aplicação dinâmica de alíquotas de desconto conforme o montante gasto.
* **Tratamento de Erros:** Validação de entradas para evitar falhas caso o usuário insira textos ou valores negativos.
* **Formatação Monetária:** Exibição dos valores formatados rigorosamente com duas casas decimais (padrão de moeda brasileira).
