⚡ Consumo de Energia Python

🎯 Objetivo do Sistema Consumo de Energia Python é um sistema leve e interativo desenvolvido 
com o propósito de ajudar usuários a calcularem o consumo elétrico mensal e o custo aproximado de eletrodomésticos com base na potência e no tempo de uso diário.


🛠️ Linguagem Utilizada Python 

📐 Fórmula UtilizadaO cálculo do consumo em quilowatts-hora por mês segue a premissa padrão da indústria elétrica considerando um mês comercial de 30 dias. 


🚀 Como Executar o Programa
Certifique-se de ter o Python instalado em sua máquina (Baixar Python).
Abra o terminal ou prompt de comando na pasta do projeto (projetos/consumo-energia).
Execute o script com o comando:python app.py

Siga as instruções interativas preenchendo o nome do aparelho, a potência em Watts e as horas diárias de utilização.
